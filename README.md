## Проекты

### 🏭 [Factron](https://github.com/Perevezentsev/factron-case) — SaaS для мониторинга OEE на производстве
Для небольших заводов (50–500 человек), которым Excel уже мало, а SCADA — дорого и долго.
- Расчёт OEE (доступность × производительность × качество), Pareto потерь, тренды, сменная форма для операторов (PWA)
- Мультитенантность, роли (админ / начальник / мастер / оператор), 14-дневный триал, лендинг с лидами
- CustDev (начальник производства, мастер, продажник) → сузил сегмент до производственного персонала

FastAPI · React · PostgreSQL · Redis · Docker · [Кейс →](https://github.com/Perevezentsev/factron-case)

### 📚 [Книжный год](https://github.com/Perevezentsev/bookbot) — Telegram-бот для учёта прочитанных книг
Продуктовый кейс: от бытовой проблемы до пилота с внешними пользователями за два вечера.
Итерации по обратной связи, встроенный бэклог от пользователей, release notes, метрики использования.

Python · aiogram · SQLite · Google Books API

- **[Журнал съёмок](https://github.com/Perevezentsev/shooting-journal)**
— локальное приложение для фотографа дикой природы: съёмочные дни и места из каталога Lightroom, карта, точки с направлением берега; дальше — погода, фенология и прогноз выездов. Python, FastAPI, SQLite, Leaflet. Данные не покидают компьютер.
Связывает каталог Lightroom, погоду и наблюдения iNaturalist / eBird, чтобы планировать следующие выезды на основе своих же прошлых результатов.
